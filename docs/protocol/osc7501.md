# OSC 7501 — Program Status Protocol (familia mapping)

Spec (vendor-neutral, rev ~0.4 as of 2026-10-10):
https://www.superlogical.com/rex/docs/build/program-status

Familia **emits** status; presentation stays in the terminal (Rex, Konsole, etc.).
This doc is the familia mapping. A TUI that *renders* records is a later PR (#123).

## Helper

```sh
. scripts/osc7501.sh
osc7501_emit working --id home/setup --app familia --msg "Building frame" --progress 40
osc7501_emit blocked --id home/setup --kind permission --msg "Approve install?"
osc7501_emit done --id home/setup --msg "Setup finished"
osc7501_query   # feature detect: OSC 7501 ; ? ST
```

CLI: `sh scripts/osc7501.sh emit|query|encode|--self-test`.

Emit is a no-op on non-TTY unless `FAMILIA_OSC7501=1`, `--force`, or
`OSC7501_CAPTURE=/path` (tests append raw sequences).

## Familia ids

| id | When |
|---|---|
| `home` | gum home canopy / session root |
| `home/<phase>` | pilot strip / instruments (phase sanitized) |
| `home/proto` | `proto_chat.sh` session |
| `home/setup` | first-time setup confirms + phases |

`app` defaults to `familia`. Hierarchical `/` ids inherit `app` from ancestors per spec.

## Wired call sites (first cut)

| Surface | States |
|---|---|
| `scripts/pilot_hud.sh` | canopy/strip/instruments/spin → `working`; ok → `done`; warn → `blocked:question`; fail → `error` |
| `scripts/familia_home.sh` | canopy via pilot; gum-missing → `blocked:question` |
| `scripts/setup_goals.sh` | confirm prompts → `blocked:permission`; pilot phases as above |
| `scripts/proto_chat.sh` | session start/wait → `working`; quit → `done`; die → `error` |

## Security

Treat `msg`/`title` as untrusted: helper strips C0/C1 controls before base64;
terminals must not treat them as markup (per spec).
