# Progress report

The hourly progress report is generated by `scripts/progress_report.py`. It
collects issue and pull request snapshots plus timestamped issue-thread and
pull-request review comments from GitHub, then produces a self-contained HTML
chart and its source JSON.

Run it locally with GitHub CLI authenticated for the repository:

```sh
python3 scripts/progress_report.py
```

The `Progress report` workflow refreshes hourly and can also be started with
`workflow_dispatch`. Each run uploads `index.html` and `progress-data.json` as a
30-day Actions artifact. It does not write generated charts back to a branch.

The chart uses UTC hour buckets. Issue-thread comments and pull-request review
comments are separate activity series; opened, closed, and merged counts come
from GitHub object timestamps. The Gantt
view shows currently open issues and pull requests updated in the 14-day window,
spanning their creation to latest update. That span is an item timeline, not a
claim about staffed effort or continuous implementation. The refresh is
hourly, but GitHub scheduled workflows may start late under load.
