### (2) Turbo: enabled in software, but the CPU sits at its 2.5 GHz base under a 2-thread load

Read-only state: `intel_pstate` active, `no_turbo=0`, `max_perf_pct=100`, scaling governor `powersave`
(the HWP default), EPP `performance`, power-profiles-daemon profile **performance**, on AC (battery full),
`cpuinfo_max_freq` 3.1 GHz, RAPL limits 25 W long-term / 31.25 W short-term, thermald active. When idle the
core reports 3.1 GHz. During every benchmark the average `scaling_cur_freq` was 2500 MHz (one cold run showed
3033), with no thermal-throttle counter increments and 59-82 C. So turbo is not switched off; something caps the
sustained clock at base, most likely the firmware/EC package power limit (15 W PL1; the RAPL MSR limits need root
to read). Gain if it were lifted: at most 3.1/2.5 = +24 % for compute-bound prefill, less for memory-bound
generation. This is an estimate, not a measurement: changing the setting was out of scope.

Big issues (>1.5x slower or memory-hungry), each filed:
1. **ngram-simple speculation on the coder (graph `speculative.coder-ngram`) can make generation 6.8x slower**
   (0.93 vs 6.37 t/s, 96 drafts / 4 accepted on a non-repetitive turn). Likely cause: a failed draft on
   Qwen3.5's recurrent layers costs a state rollback and re-evaluation. The 2026-10-10 2.2x win was on full-file
   echo edits only. Filed as #82.
2. **The coder's first-turn TTFT is 4.7x raw (prefill 4.9 vs 23.4 t/s on a 36-token prompt).** Likely cause:
   the graph runs the **Vulkan** build with `-ngl 0`, and llama.cpp still offloads batched matmuls to the HD 620
   (op offload), plus the slow CPU q8_0 KV path. Candidates: the CPU build for `ngl: 0` nodes, or `--no-op-offload`.
   Filed as #83.
3. **hermes's fixed prompt is 13,430 tokens** (27 tool schemas = 46.7 KB). On miryam's coder (exact serve.sh args) one replay of that prompt size had not finished prefill after 1080 s (76 % done). Raw-baseline TTFT for a 36-token prompt is 1.56 s; this is several hundred times longer on turn 1, though `--cache-ram` should make later turns reuse it. Filed as #85.
4. **The graph coder's runtime path points inside the familia checkout** (`code-bootstraps-llama.cpp/bin/...`),
   which has no binaries on miryam, so `serve.sh coder` exits 127 there until the runtime is fetched.
   Filed as #84.
