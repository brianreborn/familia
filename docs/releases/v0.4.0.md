## Scope (agreed)

Must land before the tag (no waivers; no known issues ship):

1. Pin coherence: keep `pins.txt` pointing at a real `code-bootstraps-llama.cpp` commit (done: #604 merged as `eccc593`, restoring `6ab58d7`; do not pin a llama.cpp SHA on that repo).
2. Main CI green, including the swarm-pull test path (#605; the path fix is on main as `e6176b8`, issue still open).
3. Integrate official [ggml-org/llama.cpp v1.0.0](https://github.com/ggml-org/llama.cpp/releases/tag/v1.0.0) (`b1b770d`) into `code-bootstraps-llama.cpp` (its `llama.cpp` submodule currently tracks `brianreborn/llama.cpp`, which has no `v1.0.0` tag), then re-pin familia to that new code-bootstraps commit. The re-pin is open PR #614 (code-bootstraps `223bd358`, build `b12359`).
4. Safe-mode / server tools: fix the launch-only `--tools` limitation ([#630](https://github.com/brianreborn/familia/issues/630)). No waiver.
   - Windows `start.bat` F-6 parity ([#631](https://github.com/brianreborn/familia/issues/631)): refuse its own `--host`, `--port` and `--api-key` argv overrides and a non-loopback bind with `--tools`, both with exit 2.
5. LFM3-1.7B-Uncensored is the advertised default; either wire it as `nodes.coder` or keep the README honest about the miryam graph still using Qwen3.5-2B.
6. Version labels: README, ROADMAP, and these release notes should say v0.4.0, not v0.1.0-rc2 / v0.3.0 as the current target.
7. swarm-pull draft validation: wire the `83e7562` `validate_draft` (#580) into `job()` ([#616](https://github.com/brianreborn/familia/issues/616)) and close the remaining #580 gaps ([#624](https://github.com/brianreborn/familia/issues/624)).
8. TR-4 at the graph layer: `node.role` must not override a fail-closed model for tools and routing ([#621](https://github.com/brianreborn/familia/issues/621); routing PR #268 is still open).
9. FreeBSD build and smoke test on llama.cpp `b12359` ([#632](https://github.com/brianreborn/familia/issues/632)).

## Deferred

LFM3 VL/Omni/Audio as default nodes, BitTorrent transport beyond PoC, coordinator-free swarm, installer depth beyond the must-lands (extra FreeBSD/macOS/AppImage installer features; FreeBSD build and smoke verification is must-land #632 and is not deferred), safe-build CPU node, SOUL glue, PQFreeBSD/green-roomz nexus audit, and the remaining v0.3.0 backlog.

## Platform verification

- **Linux:** the llama.cpp v1.0.0 pin proposed in open PR #614 (code-bootstraps `223bd358`, build `b12359`) is built and tested on Linux (CPU and Vulkan). It lands with #614; main's `pins.txt` is still `6ab58d7`.
- **Windows / PowerShell: unverified.** qodesh and shalom were offline, so the `b12359` Windows archives (including CUDA 13.5) and the `.ps1` scripts are untested. `start.bat` F-6 gaps (#631): its own `--host`/`--port`/`--api-key` argv is ignored (exits 0, not 2), and a non-loopback `FAMILIA_BIND` with `--tools` in `FAMILIA_EXTRA` is not refused.
- **FreeBSD / macOS: untested** for the v1.0.0 pin. The FreeBSD build and smoke test is must-land #632.
