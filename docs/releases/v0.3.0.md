## How this file is generated

This file is the working index for the v0.3.0 release. Hand-written sections can be edited in place. The Closed issues, Merged pull requests, and Planned / still open count are regenerated from GitHub with:

    sh release/scripts/release-notes.sh --write docs/releases/v0.3.0.md

The script is read-only against GitHub. It lists closed issues on the v0.3.0 milestone, pull requests merged to main that are on that milestone or that close those issues, and the count of still-open milestone issues.
