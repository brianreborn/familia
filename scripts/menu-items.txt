# familia menu items: one table for familia-menu.sh (POSIX) and familia.cmd (Windows).
# key|group|label|posix command|gate|need|windows command
#   gate: lic = run scripts/licenses.py gate first
#   need: file:PATH or grep:PATH:TEXT; shown but disabled until it holds
#   {NAME:prompt [default]} is asked for, or taken from --run KEY ARG... in order
#   PY = python3 (or $PYTHON); INSTALLER = this platform's installer; PAGER = $PAGER or more
#   empty windows command = not available on Windows
#   empty posix command = Windows only (hidden by familia-menu.sh)
#   every user-facing script must appear here; internal-only ones are listed in scripts/menu-internal.txt
