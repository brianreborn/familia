# familia menu items: one table for familia-menu.sh (POSIX) and familia.cmd (Windows).
# key|group|label|posix command|gate|need|windows command
#   gate: lic = run scripts/licenses.py gate first
#   need: file:PATH or grep:PATH:TEXT; shown but disabled until it holds
#   {NAME:prompt [default]} is asked for, or taken from --run KEY ARG... in order
#   PY = python3 (or $PYTHON); INSTALLER = this platform's installer; PAGER = $PAGER or more
#   empty windows command = not available on Windows
setup.configure|Set up|Get or update the pinned parts (code-bootstraps, green-agentz, ...)|sh scripts/configure.sh|lic||
setup.licenses|Set up|Review the licenses of everything you have chosen|PY scripts/licenses.py review|||python scripts\licenses.py review
setup.settings|Set up|Change launcher settings (port, threads, context) on the terminal|sh scripts/configure.sh --interactive|||
setup.panel|Set up|Change launcher settings in a browser form (127.0.0.1:9932)|PY scripts/panel.py|||python scripts\panel.py
setup.install|Set up|Install or update this host (llama.cpp runtime, host entry): dry run first|sh INSTALLER --dry-run|||powershell -NoProfile -ExecutionPolicy Bypass -File install\windows\install.ps1 -DryRun
skills.menu|Skills|Bundled skills: switch skills on/off for an agent (license-checked)|PY scripts/skills.py menu --agent {AGENT:agent name [hermes]}|||python scripts\skills.py menu --agent {AGENT:agent name [hermes]}
skills.list|Skills|List every skill with its license and status|PY scripts/skills.py list|||python scripts\skills.py list
skills.vendor|Skills|Show the plan to bring a survey skill into green-zkillz (no changes)|PY scripts/skills.py vendor {SKILL:skill id} --dry-run|||python scripts\skills.py vendor {SKILL:skill id} --dry-run
skills.validate|Skills|Check the skills catalog and the skills in graph.yaml|PY scripts/skills.py validate|||python scripts\skills.py validate
models.add|Models|Add a model from a Hugging Face folder or a .gguf (dry run)|scripts/add-model.sh {PATH:model folder or .gguf file} --dry-run|||python scripts\add_model.py {PATH:model folder or .gguf file} --dry-run
models.check|Models|Check graph.yaml: models, RAM budget, required launch parameters|PY scripts/validate_graph.py --graph graph.yaml|||python scripts\validate_graph.py --graph graph.yaml
models.explain|Models|Show the exact launch parameters for one node|PY scripts/validate_graph.py --graph graph.yaml --explain {NODE:node name, e.g. coder}|||python scripts\validate_graph.py --graph graph.yaml --explain {NODE:node name, e.g. coder}
models.licenses|Models|List model, skill and engine licenses (records nothing)|PY scripts/licenses.py list|||python scripts\licenses.py list

agents.hermes|Agents (hermes)|Hermes on the graph coder node (64K context)|scripts/hermes.sh|lic||
agents.hermes-render|Agents (hermes)|Write the hermes config only; start nothing|scripts/hermes.sh --render-only|||
