# familia(1) subcommand names: words|target
#   target = a menu item key (scripts/menu-items.txt): `familia WORDS [VALUE...] [ARG...]` runs that item,
#            with the same license review and dry-run, values for {NAME:...} given as args or flags.
#   target = raw|posix command|gate|windows command|summary: pass every ARG to that command.
# Every menu item is also reachable as `familia KEY`, `familia GROUP NAME` (e.g. familia hosts serve) and,
# when the part after the dot is unique, `familia NAME`. The first name listed here for a key is the one
# help and the man page show. Longest match wins.
